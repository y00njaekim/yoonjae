---
name: fork-to-tmux
description: 현재 Codex 대화를 지정한 tmux pane에 fork해서 연다. "$fork-to-tmux 1:2.1" 또는 "이 세션을 tmux에 fork해줘" 요청에 쓴다.
---

현재 대화를 `codex fork`로 분기하여 `session:window[.pane]` 대상에 연다. 원래 대화는 유지하며 작업 디렉터리는 공유한다.

1. 대상이 주어지면 이 스킬 폴더의 `scripts/fork.py`를 실행한다. 대상이 없으면 대상만 묻는다.
   ```bash
   python3 <이 스킬 폴더>/scripts/fork.py '1:2.1'
   ```
2. 스크립트는 `CODEX_THREAD_ID`와 현재 작업 디렉터리를 사용한다. ID가 없으면 현재 대화의 정확한 ID를 확인하여 `--session-id`로 전달한다. `--last`는 다른 대화를 고를 수 있으므로 대체 수단으로 사용하지 않는다.
3. 없는 세션·윈도우·pane은 생성한다. `.pane` 생략 시 0이다. 기존 pane은 셸이 전면에 있을 때만 입력한다. 셸 이름 확인만으로 빈 프롬프트까지 보장되지는 않으므로 사용자가 입력 중이라고 알려준 pane은 사용하지 않는다. 실행 중인 프로그램을 중단해 자리를 만들지 않는다.
4. 출력된 생성 내역과 명령 전달 결과를 보고한다. 명령 전달은 Codex 시작·로그인·fork 성공의 확인과 다르다. 실패하면 오류를 보고하고 멈춘다.

`--dry-run`은 변경 없이 대상과 실행 명령을 출력한다. 다른 작업 디렉터리가 요청되면 `--cwd`를 사용한다. 이 기능은 Git worktree를 만들지 않는다.
